    3 · timescales

    How long each memory lasts

    My thesis is about timescales: one mechanism for when to write, one for how long a write lasts. Here's the network's clock next to the brain's, on a log scale.

    Network times are in N-MNIST recording time: each sample's ~300 ms is cut into 25 steps of about 12 ms. The 128 samples in a batch run side by side, so the network experiences much less time than the data contains. Treat these as rough conversions. The bottom row is the point: a weight in this network holds its memory for about one task, while a brain synapse can hold one for a lifetime.
